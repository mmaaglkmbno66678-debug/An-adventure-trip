# 🏴‍☠️ رحلة البحث عن الكنز — Treasure Hunt

لعبة تعليمية تفاعلية عربية (RTL) بأسلوب مغامرة بحرية، مبنية بـ HTML/CSS/JavaScript خالص، وتعمل مباشرة بفتح الملف دون خادم أو اتصال إنترنت.

## التشغيل
افتح `index.html` في المتصفح (Chrome / Edge / Safari)، ثم اضغط **ابدأ المغامرة**.

## الملفات
- `index.html` — الشاشات والرسوم والمؤثرات العامة.
- `css/style.css` — الهوية البحرية، الحركات، والتصميم المتجاوب.
- `js/questions.js` — بنك الأسئلة الخمسة عشر بنصوصها الأصلية وترتيبها كما ورد في التكليف.
- `js/game.js` — منطق اللعبة، النقاط، الحفظ، السحب والإفلات، المؤقت، والصوت.

## ما تم تنفيذه
- شاشة بداية متحركة + سفينة تبحر نحو الجزيرة + خريطة بست جزر تُفتح تدريجيًا.
- خمسة أنماط أسئلة: اختيار من متعدد، صح/خطأ، أكمل الفراغ، توصيل بالسحب والإفلات، ترتيب بالسحب والإفلات، وتحدي نهائي بمؤقت.
- ١٥ سؤالًا فقط، دون إضافة أو تعديل في نصوص الأسئلة والإجابات.
- نقاط، شريط تقدم، قطع خريطة، مكافآت بصرية عند إكمال كل قسم، ومفتاح الصندوق في النهاية.
- مؤثرات بصرية مستمرة وتفاعلية (أمواج، فقاعات، طيور، غيوم، لمعان، تموج عند النقر).
- مؤثرات صوتية مولّدة محليًا عبر Web Audio API + زر كتم شامل.
- حفظ تلقائي للتقدم في `localStorage`، شاشة نهاية تفصيلية، وإعادة المغامرة.
- تصميم متجاوب للجوال والتابلت والكمبيوتر مع دعم RTL كامل.

## الاختبار
تم اختبار المسار الكامل (١٥/١٥)، الإجابة الخاطئة، انتهاء المؤقت، السحب والإفلات للتوصيل والترتيب، فتح الصندوق، عرض النتيجة، إعادة المغامرة، الحفظ بعد إعادة التحميل، وزر الصوت.
